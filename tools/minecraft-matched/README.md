# Matched terrain benchmark mod

This isolated Fabric 1.21.1 test mod generates the same bounded, standard-size colored blocks as Space's `MatchedTerrainSpec.ts`. It does not include Minecraft, Sodium, Distant Horizons, or other third-party binaries.

## Terrain contract

- Seed 42, 1024 × 1024 horizontal unit cells; air outside the boundary.
- Integer bilinear noise at 64 m and 16 m scales; solid columns from y=0 through the generated height.
- 256 opaque constant RGB colors, selected independently for every unit block by a deterministic integer hash.
- No textures beyond a single-color texel, no microvoxels, plants, fluids, mobs, structures, or caves.
- Canonical full-volume stream: z outer, x inner, height+1 as u8, then RGB u8 values for y=0..height. CRC32 `bef315c8`, 48,810,696 solid cells.
- Space translates local coordinates by (+7680, 0, +512) to fit its existing world storage; the rendered projection is flat.

## Build and play

Use Java 21 and Gradle 8.10.2: `gradle build`. The mod JAR is written under `build/libs/`. The palette textures and models are generated by `generate-assets.py`; generated output and Gradle caches are ignored.

Install only Fabric Loader, Fabric API, Sodium, Distant Horizons, and this mod in a separate game directory. Create a new world with the **Space matched unit blocks** world preset. Never replace an existing world's generator.

Alternatively, `create-save.py TEMPLATE_LEVEL_DAT NEW_DIRECTORY` creates a new save from a test world's metadata with the matched generator, creative flight, fixed noon and no spawning. It refuses an existing destination. It requires Python `nbtlib==2.0.4`; no region, entity, player-data, or LOD database files are copied.

## Explicit automated benchmark mode

Normal play has no automatic movement or benchmarking. Add `-Dspacebench.enabled=true` only to the isolated test instance and open the new matched save. The mod refuses other generators. It validates every generated solid block plus the first air cell over every column, saves the prepared chunks, and then warms distant rendering. Default warmup is 180 seconds; `-Dspacebench.warmSeconds=60` was used for the already prepared rerun.

The benchmark fixes an eye position (512.5,96,512.5), Minecraft yaw 180°, pitch 18°, vertical FOV 70°, vanilla distance 8 chunks, and DH radius 64 chunks. It sets a 640 × 360 logical window on this Retina Mac, then requires an actual 1280 × 720 framebuffer; other DPI configurations must adapt the logical size before sampling. VSync is disabled and Minecraft's 260 FPS setting means unlimited. Each of eight balanced DH-on/off blocks has 5 seconds warmup and 10 seconds sampling. Raw frame intervals, mod inventory, renderer, and dimensions are saved to `matched-minecraft.json`. Screenshots are taken outside measured intervals. Menus, pause, and resolution mismatch abort sampling.

`matched-validation.json` describes full chunk validation. Its traversal CRC has chunk order and includes the air sentinel, so it intentionally differs from the canonical volume CRC. The engine's `matched-terrain.test.ts` independently checks the canonical stream and actual Space chunk cells.

The native OpenGL and browser WebGPU pipelines have different shading, LOD quality, simulation, and presentation. This fixture aligns source data, view, units and pixel count; it does not make their frame times an isolated ranking of algorithms.
