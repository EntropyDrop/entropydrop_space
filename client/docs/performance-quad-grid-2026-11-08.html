Accepted sessions and exclusions

The stationary table uses all 18 completed stationary blocks from the first session, before a later export hit the 64 MiB request limit. Its incomplete moving workload is not used in the main table. JSON transport was then compressed outside timing. A subsequent session developed repeated WebAssembly memory reservation failures and caught terrain-connection rebuild errors; that entire session is excluded. Developer Tools was found open after that session. Its retained state was cleared and the panel was explicitly closed and verified before the final independent 18-block moving rerun. The precise cause of the memory reservation failure is not established.

The final moving rerun has zero captured console errors, zero WebGPU errors, and window focus throughout every sampled frame. It retains the same rendering implementation and workload settings. Each workload therefore has one accepted, internally interleaved comparison, from two separate sessions. The earlier harness did not capture caught console.error messages; it now does. A completed export alone is insufficient to validate a performance run.

Implementation and image checks

Unlit solid shares production positions, base colors, emission output and ownership masks, but removes scene-light and BRDF evaluation. Grid rendering first draws the same filled triangles with color writes disabled and a small polygon depth bias, then draws indexed native one-pixel line segments after all terrain depth bundles. Each original quad becomes four edges; triangle diagonals are absent. Adjacent faces can share coincident edges; this trial does not globally deduplicate them. Greedy merged faces retain their perimeter, not an invented one-metre subdivision. LOD faces likewise retain their own quad perimeters.

The depth fill is included in the grid cost, along with extra line indices, vertex deformation and line draws. It keeps terrain occlusion; disabling it is only a visual diagnostic. Grid lines use base terrain colors. Line width is one framebuffer pixel (half a CSS pixel at DPR 2); thicker anti-aliased lines would be a separate experiment. Terrain material substitution and cached edge maintenance run in all three roles, so absolute FPS includes common diagnostic overhead, recorded as trial.hookMs. No raycasting, visibility or terrain-accuracy reduction is used.

In the accepted stationary samples, the grid retains 856,460 terrain triangles for depth and adds 1,712,920 line segments. Whole-scene draws increase from 134 to 266. This is a measured cost of this implementation, not a claim that every possible grid shader must be slower.
