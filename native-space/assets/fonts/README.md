# Native pixel font

`fusion-pixel.ttf` is the uncompressed TrueType form of the existing Web asset,
`client/src/assets/fonts/fusion-pixel-12px-proportional.woff2` (version 2026.02.27).
Glyphs, names and metrics are unchanged. Reproduce it with
`python3 native-space/tools/ui-font.py` after installing `fonttools` and `brotli`.
